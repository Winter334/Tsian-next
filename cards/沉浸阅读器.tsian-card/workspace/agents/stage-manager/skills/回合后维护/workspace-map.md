# 维护资料说明

当前入口只有本目录 SKILL.md 的 lookup / submit_changes。程序准备语义上下文并完成路径、标识、引用、数值、记忆编号和原子落盘，不要求场记读取路径地图或手写文件。

依据是已落定正文、玩家确认的必要前提、已有本局资料。首次维护可以没有任何实体；维护成功后 runtime 的主角/地点/场景引用应完整。对象未注入不等于不存在，创建前必须经过候选检查。同名不同对象明确区分，名称不是 ID。

历史时间线复用 turn.meta.recall 的摘要，只展示 important 标记对应的已发生节点；不维护原著进度/对齐信息，不读原著。records / seeds / recall 分类保留。

存储/渲染维护者需要完整结构时查阅 docs/novel-airp-schema-guide.md；它不是玩法 Agent 的工作协议。旧原始工具不再启用。
